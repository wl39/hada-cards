# Provenance

The renderer, React adapter and 48 original backgrounds were extracted from HADA by its owner (wl39). This package is MIT licensed. It contains no HADA accounts, tasks, palettes from external catalogs, schedules, credentials, database or deployment configuration.

HADA separately uses four adaptations from React Bits (Silk, Iridescence, Threads, Balatro). Their code and assets are deliberately absent from this package and studio because their license differs. The reserved shader indices 4–7 preserve HADA's saved artwork compatibility; they do not expose those backgrounds. HADA supplies those implementations as an application-only extension.

Third-party runtime code is not bundled in the npm tarball. The optional React entry point requires the application's React. Development dependencies retain their own licenses.
